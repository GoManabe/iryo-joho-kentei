# 医療情報基礎知識検定 学習アプリ

`index.html` をダブルクリックすればブラウザで開けます。オフライン動作・インストール不要。
学習記録（★・成績）は開いたブラウザの localStorage に保存されます。

- **[index.html](index.html)** … 学習アプリ（用語集・一問一答・ドリル・模擬試験・成績）
- **[textbook.html](textbook.html)** … 図解テキスト（読み物。アプリのホームからも開けます）

## スマホで使う（GitHub Pages）

GitHub Pages で配信しています：<https://gomanabe.github.io/iryo-joho-kentei/>

- **iPhone**：Safari で開く → 共有ボタン →「ホーム画面に追加」
- **Android**：Chrome で開く → メニュー →「ホーム画面に追加」（または「アプリをインストール」）

ホーム画面から起動するとアプリのように全画面で動き、一度開けばオフライン（機内・地下鉄）でも使えます。
学習記録は端末ごとに保存されます（PCとスマホで別々）。引き継ぎたいときは「成績」タブの書き出し／読み込みを使います。
※iPhoneは「Safariで開いたとき」と「ホーム画面から開いたとき」でも記録が別になるため、ホーム画面からの起動に統一してください。

### 更新の反映

PCで編集・`python build.py` したあと、このフォルダで `git add -A && git commit -m "…" && git push` すれば1〜2分でサイトに反映されます。
スマホ側はオフライン用キャッシュを使うため、**更新後は2回目の起動から**新しい内容になります。

## 図解テキスト（textbook.html）

用語集を読む前に全体像をつかむための入門書です。7章立て＋略語一覧。

- **図解23点**（保険診療の流れ、病院の部門構成、五大装置、ネットワーク機器、共通鍵と公開鍵、病院情報システムの全体像、標準規格の守備範囲、箱ひげ図 ほか）
- **略語の読み解き**　IT用語を英単語ごとに区切って日本語をあてる形式（例：PACS ＝ Picture 画像／Archiving 保管／and Communication 伝送／System システム）
- 章末に「この章のチェック」、本文中に「ひっかけ注意」

## 機能

- **用語集** — 7大分類×25中分類のツリー、全文検索（ハイライト付き）、【発展】の表示切替、★「覚えた」マーク、未習得のみ表示
- **一問一答** — 用語→意味／意味→用語のフラッシュカード。範囲指定、★済みスキップ、Space でめくる
- **ドリル** — 分野別四択の即時採点。厳選問題／自動生成／両方を選択可。キー `1`〜`4` で解答、`Enter` で次へ
- **模擬試験** — 本番同様の80問・60分。公式の出題配分（12/14/8/14/14/10/8）どおりに出題。番号パレット、見直しフラグ、領域別得点、全問解説
- **成績** — 模試履歴、分野別正答率、間違えた問題の一覧と「間違いだけ再挑戦」、学習データの書き出し／読み込み

## 試験の基本情報

- 実施団体：日本医療情報学会 医療情報技師育成部会
- 出題形式：四者択一 80問（マークシート）／試験時間 60分
- 合格基準：得点率75%（80問中60問正解）
- 実施時期：原則 6月上旬・11月上旬の年2回／受検料 5,000円（税込）／受検資格なし

## ファイル構成

```
apps/iryo-joho-kentei/
├── index.html          ← 学習アプリ（これを開く）
├── textbook.html       ← 図解テキスト（手書きHTML。ビルド不要で直接編集する）
├── README.md
├── manifest.webmanifest ← ホーム画面追加用（PWA）
├── sw.js               ← オフライン対応（Service Worker）
├── icons/              ← アプリアイコン
└── build/
    ├── build.py        ← ビルドスクリプト（python build.py で index.html を生成）
    ├── template.html   ← アプリ本体（HTML/CSS/JS）。__DATA__ にデータが埋め込まれる
    ├── parse2.py       ← 用語集PDF → glossary.json 変換（PyMuPDF使用）
    ├── glossary.json   ← 抽出済みの用語データ（790語）
    └── q1.json〜q7.json ← 厳選問題（大分類ごと）
```

### 問題を追加する

`build/qN.json` に以下の形式で追記し、`python build.py` を実行するだけです。

```json
{"cat":"503","q":"問題文","c":["選択肢1","選択肢2","選択肢3","選択肢4"],"a":0,"e":"解説"}
```

- `cat` … 中分類コード（101〜702）
- `a` … 正答の添字（0〜3）

ビルド時に「選択肢が4つあるか」「正答番号が範囲内か」「中分類コードが実在するか」「問題文が重複していないか」を自動チェックします。

### 用語集を最新版に差し替える

新しい用語集PDFが出たら、`python parse2.py <PDFのパス>` を実行 → `glossary.json` が更新され、`build.py` で反映されます。
